## 🎨 Color Scheme

Primary: Purple/Indigo (#6366f1)
Secondary: Purple (#8b5cf6)
Accent: Pink (#ec4899)
Background: Gradient from Slate-50 to Slate-100

## ✨ Animations Included

1. **Header**: Slides down on page load, changes on scroll
2. **Hero**: Stagger animations for text, rotating avatar
3. **About**: Fade in on scroll, cards hover effects
4. **Skills**: Scale and rotate on hover
5. **Projects**: Slide up on scroll, lift on hover
6. **Contact**: Form field focus animations
7. **Footer**: Heartbeat animation on heart icon

## 📱 Responsive Features

- Mobile: Single column layout, hamburger menu
- Tablet: 2-column grids
- Desktop: 3-column grids, full navigation

## 🎯 Interactive Elements

- Smooth scroll navigation
- Hover effects on all cards
- Form validation
- Click animations (scale)
- Social media links
- Project demo & code links
